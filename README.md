## 可以做什么

- 按品牌、手机型号或店内条码查库存。
- 新增型号、补货、卖出、盘点和记录售价。
- 导入批发商 Excel，查看进货批次。
- 导出顾客目录、编辑用 Excel 和条码标签。
- 使用中文、意大利语或西班牙语界面。
- 在同一店内 Wi-Fi，用手机配对查货、卖出、补货和盘点。
- 用「百货工具」查询电池编号、设计打印标签、管理店铺收支。

## 第一次打开

1. 下载 ZIP，右键选择“全部解压”。
2. 打开 `PhoneCaseInventory` 文件夹，运行 `PhoneCaseInventory.exe`。
3. 保留完整目录，不要单独移动 EXE 或删除 `_internal` 文件夹。
4. 分享版自带公共品牌与型号目录，初始数量全部为 0；自行录入或导入自己的库存。

电脑端为 Windows 桌面程序；1.6.0 起可手动开启店内手机网页入口。正式导入 Siyou 的格式及库存更新方式尚未验证。

## 百货工具（1.7.0）

**找电池：** 输入 392、377、SR626SW、V392 等完整编号，查看对应品牌编号、规格、来源和关联库存。内置 12 种常见银氧化物型号，参考资料来自 [SII 制造商对照表](https://www.sii.co.jp/en/me/battery/products/silver-oxide/cross-reference/)。可手工添加其他参考，标记为人工资料。W/SW、材质、电压和同尺寸不同类型分别显示，不按尺寸自动认定可替换。需要手动关联或新增本店商品后才显示实际库存，不自动创造库存。一个双标商品可显式关联多个参考编号，仍共用原库存和固定条码。

**标签中心：** 安装 Zebra 或其他打印机的 Windows 驱动后选择打印机，按实际纸张选择 40×60、60×40 或自定义尺寸，设置边距、水平/垂直偏移。黑标、间隙、耗材类型及走纸校准在驱动/打印机中设置，先打印一张核对尺寸和扫码。可预览、导出 PDF、提交队列，每项最多 50 份；普通手机的库存行可点「打印标签」。自动处理手机任务首次默认关闭，需要电脑主动保存开启。系统接收不代表纸张已出，异常任务不会盲目自动重打。队列保存当时标签快照，默认不复制内部批次备注；修改标签内容不修改商品本身的价格或条码。电脑与手机需保持连接。

**店铺收支：** 首次设置账本密码，先新增现金、银行等账户并填写期初日期/余额，再新增待收款或待付款，实际收付时选择账户、日期和金额；支持部分付款。账户互转使用「账户转账」，避免重复计收款。按月重复只生成待收付，不执行付款；可停止重复。工资、房租、水电、银行/POS 费用、会计师费、税费及 F24 均可分类手工登记，并存 PDF/JPG/PNG 凭证（每份 5MB 内）。Excel 包含收付款、待收付、账户当前余额、月度和付款分类；年度选择筛选已收付及图表，未结清账单展示全部日期。

库存卖出不会自动生成账本收款。图表是已登记的现金流水和收支结余，不是会计利润或税额计算。刷卡入账与后续银行到账请关联为账户转账，避免重复记收入；F24 按会计师资料登记金额、到期日与凭证，不进行税务申报。

账本入口有独立密码，老板手机请从账本里的「老板手机连接」扫描专用二维码。普通库存二维码无权读取或修改财务；可单独关闭老板手机连接。密码仅限制软件入口，不加密数据库和完整备份文件，请妥善保存。本地网络使用 HTTP，未加密传输，勿开放公网。库存备份包含账本和附件；清空库存保留账本。

打印功能已设计为 Windows 驱动输出，具体 Zebra/杂牌型号及真实耗材的走纸、定位和扫码仍需现场试打确认。

## 手机怎么连接

1. 电脑点击顶部「手机连接」→「开启连接」，保持软件开启。
2. 手机连接同一店内 Wi-Fi，用手机相机扫描电脑显示的二维码，或打开复制的配对链接。
3. 输入使用者姓名，查找型号或输入店内条码，选择卖出、补货或盘点，核对后确认。
4. 操作记录保留填写的姓名，姓名并非实名验证。每条库存为独立批次，盘点只填写该批次剩余件数。

无需购买服务器、安装手机 App 或注册云账号。仅在可信店内网络使用，HTTP 传输未加密，请勿转发配对二维码／链接或设置公网端口映射。配对者均可操作库存，库存操作权限相同，账本使用独立老板配对权限；当前没有远程访问、离线写入或摄像头商品扫码。

连接失败时，检查电脑是否休眠、是否连同一 Wi-Fi，允许 Windows 防火墙的**专用网络**访问，并检查访客网络／客户端隔离。软件不会自动修改防火墙或路由器。多网卡电脑可以在连接窗口切换地址。

关闭连接窗口仍保持连接；「关闭并断开所有手机」或退出电脑软件才会停止。重新开启需重新扫码。网络异常后请使用「重试同一操作」确认结果，不要换设备重复录入。

## 更新已有版本

**1.4.1 起支持软件内更新：** 右上角点击「检查更新」，发现新版后点击「下载并更新」。程序下载并校验作者签名的完整更新包，自动备份当前库存，再启动新版；新版成功打开后更新桌面快捷方式。库存保留，旧程序与备份保留。只有用户检查更新时联网，不上传库存。

**1.3.2 及更早版本需要先手动更新一次：**

1. 在旧版“库存管理”中点击“备份”，保存一份自己的库存备份。
2. 关闭旧版，下载并完整解压新版到新的文件夹。
3. 在同一台电脑、同一个 Windows 用户下启动新版，继续读取分享版原有库存。
4. 将原来的桌面快捷方式改为指向新 EXE，只保留一个入口。

分享版库存与设置保存在 `%LOCALAPPDATA%\CaseStudioCommunity`，与程序文件分开保存。新版首次初始化不会清空已有库存。不要删除这个数据目录，也不要把别人的数据库覆盖进来。自定义数据目录的用户手动更新时应继续指定原目录；软件内更新会自动沿用当前目录。

个人版使用独立的数据目录；不要混用个人版与分享版来更新自己的库存。旧程序和数据备份可保留；涉及数据格式升级时，不要直接用旧版打开已升级的数据。
